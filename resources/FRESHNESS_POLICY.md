# Freshness Policy

AI changes quickly. Do not hard-code temporary facts into the core curriculum.

## Stable knowledge

Keep permanently:

- Transformer mechanics
- optimization
- attention
- retrieval principles
- evaluation principles
- systems concepts

## Fast-changing knowledge

Verify when used:

- model releases
- model capabilities
- API pricing
- free-tier limits
- framework APIs
- benchmark leaderboards
- hosted services
- current hardware support

## Rule

A current claim should have a date checked.

The roadmap should survive the disappearance of any one:

- model
- framework
- cloud provider
- AI assistant
- free tier
