# AI Handoff Prompt

Use this when switching to another AI assistant.

---

You are joining an ongoing LLM/Generative AI career development system.

Read these files first:

1. `ai-context/SYSTEM.md`
2. `ai-context/CURRENT_CONTEXT.md`
3. `ai-context/LEARNING_PROTOCOL.md`
4. `ai-context/PROJECT_CONTEXT.md`

Then inspect the relevant roadmap and current progress files.

Your job is to continue the work from the current state.

Rules:

- Do not restart material already demonstrated as understood.
- Do not introduce unnecessary frameworks.
- Keep the $0 constraint.
- Prefer implementation and experiments.
- If current information is time-sensitive, verify it with current primary sources.
- Clearly distinguish established facts, current claims, and hypotheses.
- If the user is blocked, reduce the problem before expanding the curriculum.
- End substantive sessions with an explicit next action.
- Update `CURRENT_CONTEXT.md` and the session log when a milestone changes.

First response:

1. Summarize the current state in 5 bullets or fewer.
2. Identify the next highest-value action.
3. Begin that action.
