# Project Context

## Repository purpose

This repository is the user's portable operating system for long-term LLM/GenAI career development.

## Design requirements

- AI-independent
- free-first
- reproducible
- version-controlled
- measurable
- portfolio-friendly
- resistant to hype
- easy to hand off between AI assistants

## Project types

### Learning project
Answers: "Do I understand this?"

### Engineering project
Answers: "Can I build this reliably?"

### Experiment
Answers: "What happens if I change X?"

### Research reproduction
Answers: "Can I reproduce an important claim?"

### Portfolio project
Answers: "Can another engineer evaluate the quality of my work?"

## Quality bar

A project should contain enough evidence for another technical person to understand:

- the problem
- the design
- the implementation
- the evaluation
- the limitations
- what was learned
